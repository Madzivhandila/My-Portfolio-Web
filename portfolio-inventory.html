Project Information

  • Project: Inventory Lifecycle Management System
  • Client: ArcelorMittal South Africa
  • Duration: 2024 - 2026
  • Category: Enterprise Web Application
  • Technology Stack: ASP.NET Core, C#, SQL Server, Paradox Database, SSRS, AD Authentication, Visual Studio and Git

Inventory Lifecycle Management System

A full-stack web-based system designed to manage the complete lifecycle of inventory used in manufacturing plants. The solution improves traceability, compliance, reporting, and operational efficiency.

Key Features

  • End-to-end inventory lifecycle tracking
  • Calibration request and approval workflow
  • Automated calibration certificates
  • SSRS subscription-based reporting
  • Role-Based Access Control (RBAC)
  • Active Directory authentication
  • Legacy system integration
  • Automated compliance reporting

Business Impact

  • Reduced manual inventory tracking
  • Improved compliance and traceability
  • Enhanced reporting efficiency
  • Improved decision-making through real-time reporting
  • Increased inventory data accuracy
